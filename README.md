#### Descripción:
Este proyecto es un sistema de punto de venta desarrollado utilizando **Django REST Framework** en el backend y **React con TypeScript** en el frontend. También incorpora **HTML**, **CSS**, y **Tailwind CSS** para el diseño y la interfaz de usuario. Está diseñado para pequeñas y medianas empresas, proporcionando herramientas completas para la gestión de ventas, inventarios y clientes.

### Características Principales:
1. **Autenticación de Usuarios**:
   - Sistema de inicio de sesión seguro.
   - Funcionalidad para cerrar sesión.
   - Usuarios administradores pueden agregar nuevos usuarios.

2. **Gestión de Productos y Categorías**:
   - Registro de productos y sus categorías.
   - Actualización y eliminación de productos.

3. **Gestión de Compras y Ventas**:
   - Registro de compras de proveedores.
   - Registro de ventas con la opción de realizar ventas al crédito.
   - Control de los pagos de clientes para ventas a crédito.

4. **Control de Inventarios**:
   - Implementación de una tarjeta Kardex con cálculo de costo promedio.
   - Control preciso del inventario para productos.

5. **Gestión de Clientes**:
   - Registro y administración de clientes.
   - Seguimiento de pagos y abonos realizados por los clientes.

6. **Generación de Reportes**:
   - Reportes detallados para:
     - Ventas
     - Clientes
     - Compras
     - Inventario
   - Exportación e impresión de reportes en formato profesional en impresora termica.

7. **Impresión de Documentos**:
   - Generación e impresión de facturas o vouchers para:
     - Ventas
     - Compras
     - Abonos de clientes

### Tecnologías Utilizadas:
- **Backend**: Django REST Framework
- **Frontend**: React con TypeScript
- **Estilos**: Tailwind CSS, CSS y HTML
- **Base de Datos**: PostgreSQL
